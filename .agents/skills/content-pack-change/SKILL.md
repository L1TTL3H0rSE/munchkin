# Content pack change

1. Run context and read `content/AGENTS.md`.
2. Confirm author/license/source, immutable identity/version, safe local assets
   and registered effect kinds.
3. Create/approve/select a plan; schema/effect changes claim backend/frontend
   consumers.
4. Never copy unlicensed commercial card text/art/trade dress.
5. Run semantic validator, invalid fixtures and consumer closure verify.
6. Scope-check and complete lifecycle.
