# Content pack change

1. Run context and read `content/AGENTS.md`.
2. Confirm author/license/source, immutable identity/version, safe local assets
   and registered effect kinds.
3. Create a skeleton plan and classify delegation before approval. For a large
   pack/schema change, give independent licensing/content, schema/effect and
   consumer checks to bounded explorers, then give the synthesized plan to a
   reviewer; for small, record why delegation is not needed.
4. Complete/approve/select the plan; schema/effect changes claim
   backend/frontend consumers.
5. Never copy unlicensed commercial card text/art/trade dress.
6. Run semantic validator, invalid fixtures and consumer closure verify.
7. Scope-check and complete lifecycle.
